# Casa Del Cocktail

The start page for the project's planning notes. This `docs` folder is an Obsidian vault, and Claude Code reads the same files.

## The plan
- [[project-brief|Project Brief]]: goals, audience, scope
- [[prd|PRD]]: user stories, screens, matching rules, data shapes, the Later and Maybe lists
- [[roadmap|Roadmap]]: the step-by-step build plan
- [[brand-kit|Brand Kit]]: colors, fonts, tone of voice and sample copy ([brand-preview.html](brand-preview.html) shows them)
- [[screens/README|Screens]]: mockups of every v1 screen

## Working notes
- [[decisions|Decisions]]: what we decided and why, with dates
- [[ideas|Ideas]]: an inbox for new ideas before they go into the PRD

## Where things stand
The latest progress is in `CLAUDE.md`'s "Current status" line, in the main project folder (one level up, outside this vault). Claude Code keeps it up to date.

## How these notes work with Claude Code
- Edit any note here as you like. Claude Code reads these files at the start of each step.
- New idea? Add it to [[ideas]]. When you decide on one, ask Claude Code to move it into the PRD's Later or Maybe list.
- Made a decision? Add a line to [[decisions]], or ask Claude Code to.
- Don't rename or move the five main docs. `CLAUDE.md` points to them by file name.
